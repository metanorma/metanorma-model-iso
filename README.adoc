# This repository has been consolidated into standoc-models

This repository — the shared grammar hub, historically misnamed with an "iso" prefix despite containing Basicdoc, Standoc, and every flavour's grammars — is now part of **[metanorma/standoc-models](https://github.com/metanorma/standoc-models)**, per [metanorma-core#16](https://github.com/metanorma/metanorma-core/issues/16).

- Grammar sources and builds now live in [`standoc-models/grammars/`](https://github.com/metanorma/standoc-models/tree/main/grammars); the shared-layer grammars are renamed after their layer (`standoc.rnc`, `standoc-presentation.rnc`).
- This repository's full commit history is preserved there.
- All open issues (including the model-driven SSOT proposal, #181) were transferred to `standoc-models`; this repository's issue and PR history remains readable here.

This repository is archived read-only. All grammar and model work happens in `standoc-models`.
